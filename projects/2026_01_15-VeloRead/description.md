Veloread is a minimalist web application based on the RSVP (Fast Serial Visual Presentation) technique, developed to maximize reading speed and focus. With ORP (Optimum Recognition Point) highlighting, it highlights the focal point of each word, increasing the processing speed of information coming to the brain and minimizing eye fatigue in long-term readings.

You can install this website as an app on nearly every device.
[VeloRead App](https://www.uluckaymak.com/apps/veloread/)
